# 鏡面彈射實驗室：即時數學動作遊戲

依最新「選取1–2個概念做即時動作玩法」需求，本次選用 `docs/imo_concepts.md` 第1.10節的鏡射對稱，製作一個60秒鏡面彈射模式。`docs/math_interactive_spec.md` 提供800×600座標、圖形互動與觸控設計參考；其第4節的五個靜態關卡並未在本次宣稱全部完成。原有13關IMO、三級幾何推理、立體及矩陣模式均保留。

## 操作與數學判定

- 從研究所的「動作彈射」進入，或使用 `?mode=action`。
- 在畫布向下拖曳拉弓後放開發射；輕點畫布、空白鍵或「發射」也能使用目前角度。向上拉與指標取消不會誤射。
- 用WASD／方向鍵或方向按鈕移動發射台。角度滑桿10–170度，90度向上。主要觸控按鈕最小44×44 CSS像素，畫布整面可瞄準。
- 左、右、上三面金色牆為鏡面；底部是出口。目標數字1或2表示需要的**精確反射次數**，不是任意反射後碰到就算成功。
- 反射使用 `v' = v − 2(v·n)n`（單位法線n）：沿鏡面的分量不變，法向分量反號，速率不變。入射角與反射角均從法線量起。最近接觸點繪製入射、反射及法線，介面顯示相等角度。
- 瞄準虛線預覽最多三個邊界接觸點；目標會移動，真正碰到目標時該球即消耗。目標與小球以可見圓形半徑碰撞，不以外圍光暈當作碰撞面積。
- 正確命中100分。連續命中1–3次為×1、4–6次為×2，以此類推，最高×5。直接命中、反射次數錯誤、落底、超過6次反射或飛行超過6個模擬秒會失誤並清空連擊。最高分不因重試歸零。
- 每次發射冷卻0.22個模擬秒，最多同時3球；目標命中後1.2個模擬秒再出現。同一個目標不能被同幀的多球重複計分。

## 物理與生命週期

- `src/types/actionGame.ts`：Player、Projectile、Obstacle、Particle、GameState及事件型別。
- `src/games/action/physics.ts`：鏡射、掃掠圓碰撞、最早牆面接觸。
- `src/games/action/engine.ts`：固定1/60秒更新，速度、玩家加速度／摩擦／邊界反彈、粒子重力與地板反彈、分數及時鐘。
- `src/games/action/render.ts`：唯讀Canvas繪圖；不修改數學或狀態。最多3球、5目標、120粒子、5個失誤波紋，每球最多12個尾跡點，避免特效無限累積。
- `src/games/action/audio.ts`：使用者手勢啟動Web Audio合成音效，低音量、短音，不下載音檔；支援靜音與不支援音效時的降級，離開時釋放AudioContext。
- `src/games/ActionMathGame.tsx`：rAF排程、Canvas、鍵盤／Pointer操作、React儀表及本機最高分。React儀表約10Hz，物理與繪圖不依賴React render。Canvas按DPR縮放，上限2，控制記憶體與填色成本。

固定60Hz是物理更新頻率，rAF由螢幕更新率與裝置負載決定，不能保證所有手機實際60FPS。每幀最多補6次物理更新；卡頓時丟棄多餘物理追趕，倒數仍扣除實際前景時間。失誤短暫以0.35倍物理速度慢動作，計時不跟著變慢。

切換分頁或視窗失焦自動暫停，回來需手動繼續，不扣背景時間。暫停／結束時停止rAF，離開元件取消排程、ResizeObserver、視窗監聽與音效，清除按鍵及拖曳狀態。即時重試重建所有盤面與暫態，不會疊加多個迴圈。尊重`prefers-reduced-motion`並提供「減少特效」開關，取消震動、粒子及失誤慢動作，數學判定和分數不變。

最高分使用獨立 `geometry-kids:action-best:v1`，不讀寫舊遊戲紀錄，不上傳兒童資料。拒絕儲存／配額不足時可繼續玩並顯示提示。Canvas不可用時顯示可讀訊息。

## 河流規格澄清

使用者已確認：箱子掉落10分鐘後船員才發現，發現前不可掉頭。已將此條件補入原文件第4節關卡2。以掉落為t=0，若第t分鐘掉頭，船與箱子共享水流速度，返回需t分鐘、總追回時間2t分鐘。故允許的最早掉頭為t=10，總追回時間20分鐘。這項澄清沒有被當成本次已實作的河流動作玩法。

## 驗證範圍

`tests/action.test.ts` 驗證反射等角／速率守恆、任意法線、掃掠碰撞與高速穿透、鏡角雙碰撞、移動目標、精確反射次數、重複計分、連擊、物件上限、摩擦／重力／反彈、不同繪圖頻率的一致性、卡頓及慢動作倒數、暫停重試、render唯讀與儲存故障。

`tests/e2e/action.spec.ts` 在桌面與手機尺寸測試拖曳、CDP觸控取消與放開發射、按鈕與鍵盤、得分／最高分、背景暫停、結束、rAF清除、重試、320px與44px操作尺寸、減少動態效果、音效不可用、儲存拒絕與離線單檔。實體手機與其他瀏覽器的FPS仍需實機驗證。
