## 必要的數學更正與教學調整

- **位值**：數字0在任何位的面值與位值都相等；不能說只有個位才相等。
- **羅馬數字**：`DCVL` 不是合法標準寫法，V不能放L前作減法。只允許 IV、IX、XL、XC、CD、CM 六種減法組合，解析後以標準寫法反查。
- **逆推**：原例終值337對應19.725。本關明確改用348，使入門過程都是整數：348→848→212→200→20。乘除的固定數不能為0，不能宣稱所有算術運算皆可逆。
- **約分**：任何大於1的公因數都能合法約分。12/32可一次÷4，也能兩次÷2；不把「未用最大公因數」誤判為錯誤。零份量可約為0/1。
- **分數比較**：兩個整體必須同樣大。通分只改刻度，不能拉長其中一條跑道。
- **度量衡**：50÷125=0.4公尺是正確的；本關改用40公分只是方便學生使用整數，不能把小數列為數學錯誤。
- **矩陣規律**：固定第1、2組所用的 `B×C+A`，第3組 `(14,x,7)→35` 必須是 `7x+14=35`，答案3。原文件中途交換節點得到2不一致。界面限定16種二運算組合並完整驗證，避免宣稱任意數列只有唯一規則。
- **羅盤**：目標同時包含轉向順序；只直接順轉1格雖也到市場，沒有完成題目指定操作。
- **對稱**：用點座標反射驗證完整輪廓。圓有無限條對稱軸，有限按鈕只作示例；不是找到幾條就宣稱找完。用平面鏡像疊圖呈現，不依賴3D渲染。

## 狀態與資料

- `src/types/game.ts`：具辨識標籤的盤面聯集、關卡介面、操作介面。
- `src/games/levels.ts`：13關初始盤面、概念、預算、三階提示與純驗證函式。
- `src/games/math.ts`：羅馬數字、整數數學、邊界、反射與羅盤計算。
- `src/games/engine.ts`：純轉移與 reducer；保留不可變快照以 Undo。
- `src/games/IMOGame.tsx`：選關、雙模式、共用操作、完成紀錄；其餘13個元件分開管理盤面。

每次真正改變盤面才計1步；改動參數也是一次操作。選取舞台／摺線、未提交的輸入、提示、重複圍同一條邊與無效數值都不扣步數。合法但不符合任務的操作會消耗步數並給出回饋。用完預算停止盤面操作；Undo會恢復上一步盤面及步數，所以能從死局繼續。成功後鎖定操作，仍可Undo或重新開始，防止重複結算。

換關、重設、切模式會重設目前盤面、歷史、步數和提示，畫面事先說明。完成紀錄不因Undo或重設刪除。新紀錄只保存已完成關卡ID，使用獨立 `geometry-kids:imo-completed:v1`，不讀寫既有三種遊戲的儲存鍵、不收集姓名或對外傳送。localStorage拒絕讀寫或配額滿時不阻止遊玩。

## 驗證與交付

`tests/imo.test.ts` 用人工解題路徑驗證13關均可在預算內完成，覆蓋每關Undo、重設、切模式、提示、成功鎖定、探索不鎖定及邊界條件。另枚舉羅馬數字1–3999、16個矩陣規則、180個整數角度的對稱軸，驗證數學更正。

`tests/e2e/imo.spec.ts` 在桌面與390px手機執行13關完整挑戰及探索；再檢查320px版面、觸控／鍵盤、耗盡步數、連點、提示、完成紀錄、舊紀錄保留、儲存被拒絕與離線四模式。原推理、立體與圖形矩陣的完整回歸仍執行。

執行 `npm test`、`npm run build:offline`、`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`。離線HTML含四個模式及版本commit；固定ZIP必須取自通過CI的該版產物並核對內嵌版本，不能拿舊ZIP充當新功能。預覽面板仍需平台支援；本機HTTP可達不代表ChatGPT預覽已恢復。
